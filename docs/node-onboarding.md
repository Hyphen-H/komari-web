# 命名节点与自动发现是两种独立接入方式

## 默认：命名创建

1. 添加节点，填写名字（例如BWSG）与分组/标签/国家。
2. 点击“创建节点并生成部署命令”，主控只创建一次节点，并返回专属UUID/Token。
3. 自动打开部署对话框，配置平台、流量重置日等安装选项；命令使用该Token，不含自动发现参数。
4. 目标机部署后只向该节点上报。关闭后从节点行的部署按钮重新打开，不要重复创建。

## 自动发现

从独立“自动发现”入口获取批量接入命令，不预建命名节点。Agent首次运行按主机名自动注册Auto-主机名，接入后再改名。

不要同时为同一目标机执行自动发现命令并创建命名节点。该问题不是通过猜测名称、IP或主机名合并解决，而是绑定明确的节点Token。

## 已存在重复记录

本修复不删除、合并或重新绑定生产记录。应先确认哪一条承载历史，再决定改名/迁移；不要直接删除在线节点。

## 回归

```sh
npm run dev -- --host 127.0.0.1 --port 5181
# 另一个终端；工作区相邻theme目录已安装Playwright时：
npm run test:node-onboarding
```

其他环境通过`PLAYWRIGHT_MODULE`指定playwright-core的模块路径/URL，通过`NODE_ONBOARDING_BASE_URL`指定开发服务。全部API均mock，不执行目标机部署命令，不使用生产凭据。

覆盖桌面/手机：失败保留输入、双击不重复、创建名称/分类、创建后专属命令、四平台Token绑定、流量重置日、关闭后重新打开、独立自动发现入口。
